# LianBroker — deploy ke Vercel

1. Extract ZIP ini.
2. Upload folder hasil extract ke Vercel.
3. Gunakan pengaturan default Vercel. File `vercel.json` sudah mengatur install, build, dan output folder.
4. Klik **Deploy**.

QR pembayaran di website adalah QR informasi yang berisi metode, nomor rekening, paket, dan nomor WhatsApp. QR ini bukan QRIS merchant resmi.
